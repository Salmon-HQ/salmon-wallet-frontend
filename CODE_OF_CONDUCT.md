# Code of Conduct

Be respectful and professional. Harassment, personal attacks, and bad-faith behavior are not tolerated in issues, pull requests, or any project space.

Report unacceptable behavior privately to the repository maintainers (via GitHub). Maintainers may edit, lock, or remove contributions and contributors that violate this policy.

This policy is intentionally short; when in doubt, follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
