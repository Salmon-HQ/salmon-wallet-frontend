buscando provider…

0 · Connect

Abre window.salmon.connect(). Requerido antes de firmar (provee la address y la public key usada como requiredSigner en OCMS).

1 · signMessage — texto normal

Firma un texto UTF-8 plano vía signMessage(bytes). Debe firmar OK (no es una transacción).

2 · signMessage — bytes que SON una transacción (guard anti-blind-signing)

Manda por signMessage bytes que deserializan como un Solana Message real. El popup debe mostrar el banner rojo "Signing blocked" y el botón Firmar deshabilitado. Sólo se puede rechazar → acá verás un error de rechazo.

3 · signOffchainMessage — OCMS v1 (PR#92)

Firma off-chain con dominio 0xff"solana offchain" vía signOffchainMessage(). El popup muestra el contenido decodificado y el/los required signer(s). Requiere Connect primero.

4 · signIn — SIWS (PR#93)

La wallet construye el mensaje SIWS y ata el domain al origin real. Dejá el campo vacío para el caso válido (usa el origin real). Poné un dominio distinto para forzar el mismatch → banner en el popup y la firma se rechaza.
