# Contract: component inventory (mobile)

Feature: [spec.md](../spec.md) · Plan: [plan.md](../plan.md)

Derived from 12 `product.pen` screens (CORE 01–09, POWERUPS 01–03). Every
screen is `vertical, gap 20 (12–18 on dense ones), padding [28,20,20,20]`.
Sizes are design references; implement with `s()`/`vs()` + flex. Colours
always via `semantic` tokens (deep-water), never the `.pen` light hex.

Legend: **keep** = exists, restyle only · **new** = build · **delete** =
remove file once consumers migrate.

## Consolidation pass (2026-09-01) — variants added

Every Home component now composes the kit; the props below were added to the
primitives rather than re-drawn as local styles in a consumer.

### `IconBubble`

| Addition                         | Why                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `size: 24`                       | The balance eye toggle. Smallest step in the scale.                                                                                                                                                                                                                                                                                                                |
| `tone: 'outline'`                | Transparent ground + `border.raised` hairline at `borderWidth.actionButton`, ink `text.primary`. The Receive circle and the portfolio visibility button. The tone's ink is primary; the visibility button keeps `text.secondary` through the explicit `iconColor` override below, because `.pen` draws it quieter than the Receive circle it shares the tone with. |
| `tone: 'ghost'`                  | Transparent, no edge, ink `text.secondary`. A bare glyph in a touch box (balance eye), which must not read as an object.                                                                                                                                                                                                                                           |
| `iconWeight`                     | Phosphor stroke weight (`bold` on Send, the FAB, the browse mark).                                                                                                                                                                                                                                                                                                 |
| `onPress` / `disabled`           | Pressable mode: `accessibilityRole="button"`, `accessibilityState.disabled`, `usePressMotion` scale + `PressSpecular`. Disabled swaps the whole object to `surface.crest` + `text.disabled` (the `PrimaryButton` rule), never a dimmed fill.                                                                                                                       |
| `flesh`                          | `FleshBackground` clipped to the shape. Defaults on for a pressable `accent` bubble, off elsewhere.                                                                                                                                                                                                                                                                |
| `hitSlop`                        | A 36–38pt bubble cannot reach the 44pt touch floor on its own.                                                                                                                                                                                                                                                                                                     |
| `rotation?: SharedValue<number>` | Degrees the caller drives itself (the FAB's plus turning into a close mark). A shared value, not a style: the press scale and the rotation are one `transform` array, and two styles each writing `transform` do not merge — the last wins, which is why the plus never turned.                                                                                    |
| `radius: 'lg' \| 'xl'`           | The two card corners a `rounded` bubble can take, named as `Card` names them (12 / 16). Default `xl`. The wallet thumb is r12 in `.pen` CORE 01 while the kit's rounded default is r16 — one drawn corner, not a second rounded shape. Ignored by `circle`.                                                                                                        |
| `iconColor`                      | Overrides the ink the tone draws — a token value only. `.pen` gives the portfolio visibility button a secondary glyph while the Receive circle, on the same `outline` tone, carries primary: the button is an adjustment, not an action. Dropped on a disabled control, which stays one object.                                                                    |

A non-pressable bubble renders exactly as before: a plain `View`, no role, no
motion, no texture.

### `ListRow`

| Addition                         | Why                                                                                                                                                                                                                                                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `titleAccessory`                 | A node beside the title on the same line — the token row's `TokenBadges`.                                                                                                                                                                                |
| `subtitle` accepts a `ReactNode` | The token row's "ticker · price · change" is one `Text` with a differently-coloured change run; a string subtitle still takes the row's own secondary style.                                                                                             |
| `emphasis: 'strong'`             | Title at `bodyLg`/700 instead of `body`/700 — an asset row is the screen's content, not an index into it.                                                                                                                                                |
| `tone`                           | Forwarded to `Card` (the accent-tint "Browse Powerups" row). Nesting a `Card` inside `ListRow` would have meant two cards.                                                                                                                               |
| `accessibilityLabel`             | Overrides the "title, subtitle" name where the row already has a translated one (token rows).                                                                                                                                                            |
| title row wraps                  | `flexWrap` + `columnGap`/`rowGap` on the title row: the accessory sits beside the title while it fits and drops to its own line when it does not. Without it the badges and the name competed for one line and both truncated (owner, first device run). |
