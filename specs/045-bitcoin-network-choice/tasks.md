# Tasks: Bitcoin network choice — "Solana + Bitcoin" or "Solana only"

**Input**: Design documents from `specs/045-bitcoin-network-choice/` (Linear DEV-204)

**Prerequisites**: plan.md, spec.md (owner decisions 2026-11-25), research.md, data-model.md, contracts/network-choice.md, contracts/ui-contracts.md, quickstart.md

**Tests**: test-first in every group. A test task is written and run before its code task, and it names the failure it must show first; the code task starts only after that failure was seen.

**Node**: every command runs from the repository root after `export PATH="$HOME/Library/Application Support/Herd/config/nvm/versions/node/v24.21.0/bin:$PATH"`. Single test files run as `pnpm --filter <package> test <path relative to the package>` (Vitest for `@salmon/shared`, `@salmon/ui`, `@salmon/extension`; Jest for `@salmon/mobile`).

**Placement rule**: every decision (whether a network may be shown, what is stored, who sees a write, where the session goes, what the warning says, what the onboarding step does) lives in `packages/shared`; the twins only draw. `SAME_SIDE_CLONE_LINES_MAX` (870) does not move.

**Clone measurement**: `node -e "import('./scripts/check-dom-parity.mjs').then(m => console.log(m.cloneLines(process.cwd())))"` prints `{ crossPlatform, sameSide }`; `pnpm check:parity:report` lists the clone pairs. Baseline on this branch: cross-platform 2264 / ceiling 2264, same-side 870 / ceiling 870.

## Owner decisions (2026-11-25)

Recorded in plan.md §Owner sign-off and §Open risks, spec.md §Clarifications and FR-024, contracts/ui-contracts.md, research.md R4 and R10, quickstart.md §4. Tasks that depend on one carry its tag.

- **Mocks** — the onboarding step, the Settings row and the confirmation of plan.md §Owner sign-off are approved as drawn. Affects groups B and C.

- **Analytics** — the automatic move from Bitcoin to Solana mainnet sends the existing `network_switched` event when consent is on; the choice itself is never reported. Affects T009, T010, T046.
- **Clone ceiling** — `CROSS_PLATFORM_CLONE_LINES_MAX` may rise to the measured number for the new twins' data lines, with the dated comment `docs/DOM-PARITY.md` asks for; copied logic is hoisted into `packages/shared`; `SAME_SIDE_CLONE_LINES_MAX` does not move. Affects T024, T036.
