# Data model: atomic wallet save (spec 046)

No existing record changes shape. One key is added (the first-save note). This file lists the records a wallet change touches, their role in the write orders (plan.md §The write orders), and the in-between states the next launch must show correctly. Rules 1–3 are defined in plan.md §The three rules.

## Stored records (`storage/types.ts:177-249`)

| Record                       | Key                                                      | Shape                                                                           | Role                                                                                                                                                                                                  |
| ---------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Wallet list                  | `salmon_accounts`                                        | `StoredAccount[]`                                                               | **Deciding write** of add, remove, edit; a thrown write is settled by reading it back (Rule 2). Not an array, or absent/`[]` while memory holds a wallet → every mutation rejects (Rule 1)            |
| Vault                        | `salmon_mnemonics`                                       | encrypted `LockedVault` (`nonce` fresh per write); cleartext for unprotected v2 | Before the list on add; after it on remove; a replaced Seed Vault entry leaves after the list. Present but unparseable, or absent while the list names a wallet or `WALLETS` exists → reject (Rule 1) |
| **First-save note (new)**    | `salmon_first_save_pending`                              | the `nonce` string of the vault the first save writes                           | Written before that vault; removed after the list (best effort); removed last by `clearAccountsStorage`                                                                                               |
| Name counter                 | `salmon_account_counter`                                 | number                                                                          | After the list; `max(counter, list length) + 1`; on adoption `max(counter, list length)` when it grows                                                                                                |
| Active wallet, network, slot | `salmon_active_account_id`, `_network_id`, `_path_index` | id, network id, number                                                          | After the list; fallback and healing                                                                                                                                                                  |
| Backup pending               | `salmon_unconfirmed_phrases`                             | `string[]`                                                                      | New mark before the vault; separate best-effort prune after the list and at launch (absent list counts as `[]`); removed by `clearAccountsStorage`                                                    |
| Unlock penalty               | `salmon_unlock_attempts`                                 | attempts record                                                                 | Removed by the discard; grows only on `IncorrectPasswordError`                                                                                                                                        |
| Legacy v2 record             | `salmon_wallets` (+ `salmon_active`, `salmon_endpoints`) | v2 shapes                                                                       | Present → not a first save                                                                                                                                                                            |
| Session key (stash)          | `derived_key_cache`                                      | `DerivedKeyCache`                                                               | Removed by the discard, by a first save before it reads or encrypts, by `clearAll` before storage; replaced by the key a supplied password derives                                                    |

No runtime record is added: the window's wallet memory (`accounts`) is the witness Rule 1 and the discard read.

## Secret identity

| Kind        | Rule 3: adopt (window does not hold W) or `DuplicateAccountError` (window holds W) | Also `DuplicateAccountError` when                                                                                                                    | Replaced when                                                | Unlisted copy dropped when |
| ----------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | -------------------------- |
| Phrase      | listed W's entry exactly equal, same starting index                                | normalized phrase equal and the new start is an index W holds on any network; or its Solana address at its start is a listed single-address wallet's | —                                                            | exactly equal              |
| Private key | listed W's entry exactly equal                                                     | its address is a listed Solana address                                                                                                               | —                                                            | exactly equal              |
| Watched     | same                                                                               | same                                                                                                                                                 | —                                                            | exactly equal              |
| Seed Vault  | same                                                                               | its address is held by a listed wallet that is not Seed Vault                                                                                        | a listed Seed Vault wallet S, same address, different secret | exactly equal              |

A listed wallet's Solana addresses: the phrase at each non-null index of its `solana-*` `pathIndexes`; a private key decoded; watched and Seed Vault from the secret. Skips are per index and per entry: an index that cannot be derived, a missing entry, an invalid phrase or an undecodable key is skipped, and the wallet's other indexes are still compared. On adoption no vault write happens and no unlisted entry is dropped.

## States the next launch may meet

| Stored state                                      | Produced by                                                                                                        | Next launch                                                         |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Note = vault nonce, list absent or `[]`           | first save stopped after its vault, before its list                                                                | discard (memory is empty at launch), welcome                        |
| Note, vault absent                                | first save stopped before its vault                                                                                | note removed, welcome                                               |
| Note, vault nonce different                       | note removal failed, then a later vault write                                                                      | note removed (inert anyway)                                         |
| Note, listed wallet                               | first save stopped after its list                                                                                  | note removed best effort; wallets load                              |
| Vault + empty list + no note                      | pre-046 failed first save; failed "Remove all"; interrupted migration                                              | unchanged: lock screen / existing-password prompt / recover refused |
| Vault key present but unparseable                 | corruption                                                                                                         | nothing removed; every mutation rejects                             |
| List present, not an array                        | corruption                                                                                                         | no discard, no prune; loader error as today                         |
| Unlisted vault entry                              | save stopped before its list; Seed Vault replace stopped before its last vault write; removal's vault write failed | invisible, kept                                                     |
| Active id not listed; unheld pair; counter behind | stops after the list                                                                                               | fallback, healing, `max` rule                                       |
| Stale mark                                        | failed or stopped save                                                                                             | pruned at the next save or launch                                   |

## Invariants asserted after every failure and every kill

1. Every listed id has its vault entry (FR-017).
2. Every entry present before is still there, except an unlisted exact copy of the secret saved, the replaced Seed Vault entry after the list, the removed wallet's entry, and the bound discard (FR-016).
3. Before the deciding write: wallets, secrets, active wallet, slot, counter, password as before, and memory untouched. After it: wallets and entries as after; active = previous (or new if its selection landed) on a held slot; counter right or one behind (FR-001, FR-004, FR-005).
4. A rejected mutation whose deciding write threw left storage without the change (Rule 2's read-back found nothing); a resolved one left it with the change.
5. At most one listed wallet per secret identity (FR-010).
6. A listed `unconfirmed` wallet is marked; after the next save or launch every mark is named by a listed `id` or `derivedFrom` (FR-018, FR-019).
7. A vault is never re-encrypted under a key a supplied password does not derive (FR-005).
